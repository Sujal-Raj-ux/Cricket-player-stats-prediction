# IPL dashboard (Vite + React)

The API must be running separately — see the [project README](../README.md).

```bash
npm install
npm run dev
```

Dev server: [http://localhost:5173](http://localhost:5173) (Vite default).

```bash
npm run build    # production bundle to dist/
npm run preview  # serve dist locally
```

Stack: Vite, React 19, JavaScript (JSX), Tailwind CSS v4 (`@tailwindcss/vite`), Recharts.

Path alias `@/*` is configured in `vite.config.js` and `jsconfig.json` (editor hints).
